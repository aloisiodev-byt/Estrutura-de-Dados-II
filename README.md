## Desafios de programação

| Desafio | Arquivos | Estrutura usada |
|---|---|---|
| Estoque | `01_.../02_Listas_Matrizes_Dicionarios/Desafio_Estoque/desafio_estoque.py` | listas e dicionários |
| Clínica | `01_.../03_Estruturas_Dinamicas/Desafio_Clinica/sistema_clinica_v1.py` e `_v2.py` | listas dinâmicas |
| Triagem hospitalar | `02_Pilhas_e_Filas/Desafio_Triagem/triagem_hospitalar_v1.py` e `_v2.py` | filas com prioridade |
| Ordenação | `01_.../00_Ordenacao/` | vetores — Bubble, Selection, Insertion e Quick Sort |
| Controle acadêmico | `01_.../01_Structs/Controle_academico_struct.c` | vetor de structs |

**Por que `_v1` e `_v2`?** A primeira versão é a solução inicial. A segunda corrige a lógica e acrescenta menu interativo. Mantive as duas para registrar a evolução.

## Abrindo os arquivos

| Extensão | Como usar |
|---|---|
| `.py` | `python arquivo.py` com Python 3 |
